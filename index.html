Automated Rating-Call Pipeline

A fully automated, agent-less version of the calling flow: order data flows through Urban Piper to unmask the customer's bridge number, Exotel places the call and plays a pre-recorded 30-second ask, and every outcome is logged for a success-rate view — no live agent required.

Flow

Stage by stage

  1. Order marked delivered trigger
    The moment an order flips to delivered, its order_id and customer reference are handed to the calling flow — this is what starts the clock.
  2. Look up the bridge number Urban Piper
    The order is searched in Urban Piper, which returns the customer's masked/bridge number for that order along with an OTP — the credential that authorises using the number for this call.
  3. Place the call Exotel
    The masked number is handed to Exotel, which dials the customer directly. No agent is involved — this is a fully automated outbound call.
  4. Play the rating ask 30-second clip
    On connect, Exotel plays a pre-recorded 30-second clip asking how the food was, and nudging the customer toward a 5-star rating.
    ⚠ exact script wording unclear from the audio — confirm with Sumant
  5. Log the outcome backend
    Whether the call connected or not, the result — picked up / no answer / cut, duration, timestamp — is written to one central table, so the whole flow rolls up into an overall success-rate view.

Success-rate metrics

Connect rate
connected ÷ total dialed
"kitne logon ne call uthaya" — the share of calls a customer actually picked up.
Full-play rate
clip_played_full ÷ connected
Of the calls that connected, how many stayed on long enough to hear the full rating ask before cutting.

Open questions for Sumant

  • Script wording — the audio cuts off after "if you like the food then…" — need the exact line(s) in the 30-second clip.
  • OTP scope — is the OTP fetched fresh per call, or once per order and reused on a retry?
  • Retry logic — if the first call goes unanswered, is there a second attempt within the 15-minute bridge window, or is one attempt final?
  • Interaction — is the clip purely spoken, or does it include a DTMF option (e.g. "press 1")? This decides whether anything beyond call completion is measurable as a conversion.
